# House Price Prediction using Linear Regression

## Project Description
This project predicts house prices using a Linear Regression model built with Scikit-learn.

## Features
- Data Preprocessing
- Feature Scaling
- Linear Regression Model
- Streamlit Frontend
- ngrok Deployment

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- pyngrok

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py

## Project Structure

linear_regression_model.joblib
scaler.joblib
